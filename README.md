# 📚 School Projects Portfolio

This repository showcases a collection of academic projects completed during my undergraduate studies at Universiti Tunku Abdul Rahman (UTAR), covering areas such as artificial intelligence, cybersecurity, embedded systems, server administration, web development, and more. Each project demonstrates practical applications of concepts learned in class, with code and implementation files included.

## 🔍 Project Highlights

### 🧠 Artificial Intelligence (AI)
Developed ML models for classification and prediction tasks.
- Applied supervised learning techniques.
- Practiced data preprocessing, model training, and evaluation.

### 📢 Advertisement System
Simulated a targeted advertisement delivery system.
- Displayed dynamic content based on basic user input patterns.

### 🔐 Cybersecurity
Hands-on lab assignments in network and system security.
- Explored encryption, hashing, and vulnerability testing.
- Gained experience in securing data and detecting common threats.

### 🌲 Data Structures
Implemented core data structures using C/C++.
- Built custom stacks, queues, trees, and sorting algorithms.
- Reinforced problem-solving and algorithm design.

### 🤖 Embedded Devices
Programmed a simple robot using Python on Raspberry Pi.
- Controlled motors and sensors via GPIO.
- Implemented basic obstacle avoidance behavior.

### 📊 Final Year Project (FYP)
**Predictive Maintenance for Server Failure**
- Built deep learning models (GRU, CNN, XGBoost) to predict server breakdowns.
- Collected and processed telemetry data from server environments.

### 🌐 InterNetworking Principles and Practices (IPP)
Simulated real-world networking setups.
- Configured routing (RIP, OSPF), subnetting, VLANs, and NAT.
- Used Cisco Packet Tracer and real hardware for exercises.

### 🛍️ Smart Shopping Mini Project
IoT-based smart shopping cart system.
- Used Node-RED, MQTT, InfluxDB, Telegram Bot API.
- Features include live product scanning, LCD price display, and payment trigger via button.

### 🧱 Object-Oriented Programming Practices (OOPP)
Developed a **Stock Management System** in Java.
- Utilized OOP principles: inheritance, polymorphism, and encapsulation.
- Included user authentication, product inventory, and file I/O.

### 💻 Programming Fundamentals
Covers basic programming logic and syntax in Python and C/C++.
- Included control structures, recursion, functions, and error handling.

### 🖥️ Server Management
Worked with server-side configuration and network services.
- Configured Ubuntu servers with Apache, NGINX, HAProxy, and Squid Proxy.
- Applied concepts from server administration and performance tuning.

### 🌐 Web Development
Created responsive web interfaces and interactive components.
- Built front-end projects using HTML, CSS, JavaScript.
- Included form validation, responsive design, and API integration.
