## 📌 Project Overview
This is a C++-based Stock Management System designed to help businesses manage product inventories efficiently. It features a structured, modular design built using object-oriented principles such as encapsulation, inheritance, and polymorphism.

The system supports:
- Adding, updating, and removing stock items
- Searching for specific items
- Recording sales and generating basic reports
- User-friendly menu-driven console interface
