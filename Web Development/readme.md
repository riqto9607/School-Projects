# 🐾 Purrfectly Meow - Cat Management Website

**Course Project – UCCD2323 Front End Web Development**  
**Universiti Tunku Abdul Rahman (UTAR)**  

Purrfectly Meow is a comprehensive cat management platform created to support cat owners with services such as daycare, boarding, grooming, training, donations, and community engagement. Built with a focus on accessibility, responsiveness, and user interaction, this website showcases both technical and collaborative skills developed during our coursework.
