# 🎟️ Cinema Ticketing System

## 📌 Project Overview
This is a C++-based **Cinema Ticketing System** created as part of a 3-person group assignment for a programming course. The system simulates basic operations of a real-world cinema, such as booking, updating, viewing, and deleting tickets.

The program uses file handling to store data in `.txt` files and includes user-friendly features for both members and admins.

## 👥 Team Collaboration
- 3 members in total
- Each member developed **at least 3 modules**
- My modules:
  - `addTicket()`: Add new ticket booking
  - `deleteTicket()`: Cancel a booked ticket
  - `searchTicket()`: Find ticket by seat or customer name

## 💡 Features
- Add, delete, update, and search ticket bookings
- View all bookings
- Store and retrieve data using text files
- Simple menu-based navigation

## 🔧 Technologies Used
- **C++** (Arrays, Functions, File I/O, Strings)
- Text file data storage
- Optional use of Structs (encouraged)
